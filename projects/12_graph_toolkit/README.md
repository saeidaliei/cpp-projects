# 12 - Graph Toolkit

Implement a small weighted directed graph with breadth-first search and Dijkstra shortest paths.

## Concepts

- adjacency-list representation
- `std::queue` and `std::priority_queue`
- structured bindings
- generic graph APIs
- infinity/sentinel values
- algorithmic complexity

## Practice tasks

1. Add DFS.
2. Return the actual shortest path, not only its distance.
3. Detect cycles.
4. Add a topological sort for DAGs.
5. Make the graph undirected with a single helper.
6. Benchmark Dijkstra against BFS on unweighted graphs.
